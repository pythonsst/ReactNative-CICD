# App Store screenshots & metadata (Fastlane)

The app is **built and submitted with EAS**. Fastlane is only used to upload the
App Store **screenshots** (and, optionally, text metadata), which EAS doesn't do.

> Note: `README.md` in this folder is auto-generated by fastlane — edit this file
> (`SCREENSHOTS.md`) instead.

## One-time setup — App Store Connect API key (no 2FA needed)

1. App Store Connect → **Users and Access → Integrations → App Store Connect API**.
2. Generate a key with the **App Manager** role and download the `.p8` (you can
   only download it once).
3. Save it here: `ios/fastlane/asc_api_key.p8` (already gitignored).
4. Export the two ids (put these in your shell profile or a local `.env` you
   `source` before running fastlane):
   ```bash
   export ASC_KEY_ID=XXXXXXXXXX          # the key's Key ID
   export ASC_ISSUER_ID=xxxxxxxx-xxxx-…  # the Issuer ID shown above the keys list
   ```

## Update screenshots

1. Drop the PNGs into `ios/fastlane/screenshots/en-US/` (see naming below).
2. From the `ios/` folder:
   ```bash
   bundle exec fastlane screenshots
   ```
   Uploads only the screenshots (no binary, no metadata) and overwrites the
   existing set for the current editable version.

### Naming & sizes
Fastlane detects the device from the image resolution, so names just need to be
consistent and ordered. We use `NN-<device>-<screen>.png`:

| File | Device (simulator) | Portrait size |
|------|--------------------|---------------|
| `01-iphone69-home.png` | iPhone 17 Pro Max (6.9″) | 1320×2868 |
| `02-iphone69-editor.png` | iPhone 17 Pro Max | 1320×2868 |
| `03-iphone69-preview.png` | iPhone 17 Pro Max | 1320×2868 |
| `01-ipad13-home.png` | iPad Pro 13″ | 2064×2752 |
| `02-ipad13-editor.png` | iPad Pro 13″ | 2064×2752 |
| `03-ipad13-preview.png` | iPad Pro 13″ | 2064×2752 |

Apple requires a 6.9″ iPhone set; the 13″ iPad set is required because the app is
universal. To regenerate, run the app on those simulators and capture with:
```bash
xcrun simctl io <udid> screenshot ios/fastlane/screenshots/en-US/<file>.png
```

## Update text metadata (optional)
Edit files under `ios/fastlane/metadata/en-US/` then:
```bash
bundle exec fastlane metadata
```
